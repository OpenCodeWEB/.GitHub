# OpenCodeWEB

> Self-sovereign, unrestricted, perpetual universal AI-native operating system.

We build the **OpenCodeWEB OS** — an open, AI-native operating system for the post-cloud era. No gatekeepers, no artificial limits, no locked-in silos. Everything we ship is open source, self-hostable, and built to stay yours forever.

## Principles

- **Self-sovereign** — you own your data, identity, and compute.
- **Unrestricted** — no artificial limits on context, scale, or autonomy.
- **Perpetual** — everything remains usable, portable, and open forever.
- **AI-native** — the operating system is designed around AI from the kernel up.
